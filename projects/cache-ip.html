Overview

Most soft-core and custom accelerator designs on FPGA either roll a bespoke cache for each project or go without one entirely. This project is a customisable multi-layer cache IP for Vivado: a single parameterisable core that can be configured for different cache sizes, associativity, and number of cache layers (e.g. L1/L2), so it can be dropped into different SoC designs without redesigning the memory hierarchy each time.
